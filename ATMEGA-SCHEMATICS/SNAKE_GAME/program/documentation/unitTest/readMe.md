# Unit Test
    This directory is dedicated to place all unit tests for the project. To create a unit test for a specific test do the following:

1. Create a directory with a meaningful name, that reflects the task being tested.

2. Create 3 .txt files within your directory
    - <testName>_diff.txt
    - <testName>_unitTest_result.txt
    - <testName>_unitTest.txt

3. Test Execution:
    **testName_unitTest.txt**

    - In this text file, create a reasonable test to file, in which your task will be tested on.
        eg: A reasonable size text to test a protocol data transfer.

    **testName_unitTest_result.txt**

    - In this text file, store the data generated through your task
        eg: Data received back through a protocol data transfer.

    **testName_diff.txt**

    - Process the expected result with the actual result with other trusted program
        eg: use diff to compare both text files.
